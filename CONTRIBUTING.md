# Contributing to Cellular Event Horizon

CEH is a research prototype. Contributions should strengthen reproducibility, falsifiability, and scientific clarity.

## Before contributing

- Read the hypothesis and validation documents in `docs/`.
- Keep temporal leakage out of prospective experiments.
- Do not present synthetic results as biological evidence.
- Add tests for new scientific or numerical behavior.
- Prefer explicit, inspectable methods over opaque scoring.

## Pull requests

Describe:
1. the scientific question or engineering problem;
2. the change made;
3. how it was tested;
4. any assumptions or limitations introduced.

Negative results, failed hypotheses, and robustness findings are valuable contributions when they are reproducible.
