# Repository Presentation

CEH is intended to read like a serious computational research project rather than a product landing page.

## Visual language

- restrained scientific typography
- dark navy / near-black surfaces
- cyan or teal scientific accent
- thin trajectory-line motifs
- high contrast
- minimal decoration
- diagrams focused on state-space geometry

## Suggested assets

- docs/assets/ceh-hero.svg
- docs/assets/trajectory-horizon.svg
- docs/assets/null-model.svg
- docs/assets/prospective-boundary.svg

Visuals should explain the hypothesis, never imply clinical capability.
