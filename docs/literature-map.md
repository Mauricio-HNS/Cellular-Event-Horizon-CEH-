# Literature Map

## Dynamical systems in single-cell biology

Recent work explicitly describes dynamical-systems theory as an organizing framework for single-cell biology, including state spaces, attractors, trajectories, manifolds and bifurcation-based transition analysis.

## Attractor landscapes and cell fate

Systems-biology research has long used attractors to represent stable cellular states and stochastic transitions between them.

## Transition states

Cell-fate transitions have also been discussed as potentially discontinuous and stochastic rather than necessarily smooth trajectories.

## Statistical mechanics

Statistical-mechanical approaches provide tools for discussing noise, criticality, tipping behavior, state convergence and cellular state manifolds.

## Stochastic modelling

Stochastic modelling is a mature framework for heterogeneous biological systems and is relevant whenever molecular or population-level noise affects observed dynamics.

## Current position of CEH

These fields establish that cellular state transitions can be studied dynamically. They do not establish the CEH construct proposed here.

The research question is therefore narrower:

> Does a prospectively identifiable transition-relevant region provide reproducible information beyond existing state, trajectory and stochastic-dynamics descriptions?

That question must be benchmarked rather than assumed.
