# Null Calibration

A dynamical detector can produce apparently strong signals even when no meaningful transition exists. CEH therefore requires explicit null calibration.

## Primary null

The first null preserves the observed feature values but destroys temporal ordering by permutation.

The question becomes:

> Is the observed maximum CEH signal unusually large relative to signals produced when temporal structure is destroyed?

## Interpretation

A small empirical p-value does not establish biological truth. It only indicates separation from this particular computational null under the tested configuration.

A failure to separate from the null is also informative: the proposed signal may be explained by generic dynamics, noise, or the chosen representation.

Future nulls should include:

- no-transition worlds;
- matched noise worlds;
- identity permutations;
- missingness-matched worlds;
- parameter-matched controls;
- negative-control interventions.

The null model must be reported alongside the positive experiment.
