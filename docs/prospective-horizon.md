# Prospective Horizon

The strongest CEH formulation is prospective.

At a cutoff time T, the system must construct its representation using only
observations x_0 through x_T.

It may then be evaluated against an outcome occurring after T.

## Research question

Does a candidate CEH region identified from the past contain information about a subsequent state transition beyond what is available from a snapshot-only representation?

## Experimental rule

The future trajectory is an evaluation target, never an input to the cutoff representation.

## Why this matters

A retrospective algorithm can describe a transition after seeing it. That is useful for analysis but weak evidence for a prospective phenomenon.

CEH therefore treats temporal information separation as a first-class experimental constraint.
