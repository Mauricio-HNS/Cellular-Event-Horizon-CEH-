# Convergence and Null Models

Convergence is central to CEH, but it is also vulnerable to false positives.

If a population becomes more compact for reasons unrelated to a meaningful transition, a naive convergence metric can report a signal anyway.

Therefore CEH treats convergence as a **comparative statistic**, not as evidence by itself.

## Primary control

The identity-permutation null preserves the marginal distribution at each time point while disrupting persistent trajectory identity.

Observed convergence should be compared with a distribution generated by repeated null permutations, not with a single shuffled value.

## Future statistical layer

The next implementation should provide:

1. repeated null permutations;
2. empirical null distributions;
3. effect size;
4. confidence intervals;
5. permutation p-values where appropriate;
6. correction for multiple tested windows;
7. preregistered decision rules.

A strong CEH result should survive these controls.

## Important limitation

The current v0.1/v0.2 geometry is not a biological discovery. It is infrastructure for testing whether a measurable convergence phenomenon exists under controlled conditions.
